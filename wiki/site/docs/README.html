HermesMacOS documentation

docs/README.md

HermesMacOS is a native SwiftUI macOS control surface for Hermes Agent. It combines prompt clients, dashboard-backed management panels, local runtime configuration, utilities, and repository maintenance workflows in one desktop app.

Start here

  • Getting started tutorial: build the app, connect it to local Hermes services, and send the first Ask Hermes prompt.
  • How to configure endpoints and saved windows: set API/dashboard hosts, API keys, self-signed certificate handling, saved endpoint pairs, and SSH credentials.
  • How to use Ask Hermes and Chat with Hermes: profiles, reasoning, attachments, streaming, cancellation, and session resume.
  • How to use the TUI Gateway tab: connect the native TUI WebSocket, use multiple TUI workspaces, send attachments, answer requests, and resume sessions.
  • How to manage Hermes runtime from the app: profiles, models, skills, MCP servers, schedules, plugins, toolsets, approvals, and repository updates.

Reference

  • Application surface reference: tabs, settings, utilities, and user-facing features.
  • API and storage reference: Hermes API routes, dashboard routes, headers, local storage, Keychain, and files touched.
  • TUI Gateway WebSocket reference: JSON-RPC setup, methods, event envelopes, stream grouping, workspace state, and attachment flow.

Explanation

  • Architecture explanation: how the SwiftUI shell, sessions, stores, dashboard client, and local runtime helpers fit together.
  • Security model explanation: why the app is unsandboxed and how it uses Keychain, encrypted retention, approvals, TLS pinning, and LocalAuthentication.
